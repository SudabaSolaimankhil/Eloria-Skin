# 🌸 Eloria Skin

A modern and responsive skincare website built as a **group project for practicing Git and GitHub collaboration**.

## 📌 About the Project

**Eloria Skin** is a skincare e-commerce website developed by students as a practical exercise in collaborative software development.

The main goal of this project is not only to build a website, but also to learn and practice:

- Git and GitHub
- Branching and merging
- Team collaboration
- Pull requests
- Resolving merge conflicts
- Commit management
- Working with a shared repository

## 🌿 Branching Strategy

The `main` branch contains the integrated version of the project.

Each student works on a separate feature branch.

Example:

```text
main
│
├── header
├── hero
├── shop
├── about
└── contact
```

### Basic Workflow

```bash
# Get the latest project
git pull origin main

# Create and switch to your feature branch
git switch -c feature-name

# Make your changes

# Stage changes
git add .

# Commit changes
git commit -m "Add feature"

# Push your branch
git push -u origin feature-name
```

After completing the feature, the student creates a **Pull Request** on GitHub so the changes can be reviewed and merged into `main`.

## 👥 Team Collaboration Rules

1. Do not work directly on `main`.
2. Create a separate branch for your assigned feature.
3. Use clear and meaningful commit messages.
4. Pull the latest changes before starting new work.
5. Push your branch regularly.
6. Create a Pull Request when your feature is ready.
7. Review and resolve merge conflicts carefully.
8. Do not overwrite another student's work without discussion.
